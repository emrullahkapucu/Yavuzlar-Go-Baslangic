# Yavuzlar – Go Başlangıç Görevleri

Siber Vatan **Yavuzlar** takımındayken Go dilini öğrenmek için yaptığım görevler (2023).

| Klasör | Ne yapıyor |
|---|---|
| `yavuzlar-go-kullanicigirişlog` | Admin ve öğrenci için ayrı giriş. En fazla 5 deneme hakkı var; her giriş denemesi tarih, saat ve sonucuyla `logs.txt` dosyasına yazılıyor. |
| `yavuzlar-go-hesapmakinesi` | Terminalde çalışan hesap makinesi |
| `yavuzlar-go-dairedealancevre` | Yarıçapı verilen dairenin alanını ve çevresini hesaplıyor |
| `yavuzlar-go-merhabasiberyavuzlar` | İlk Go programı |

## Çalıştırma

```bash
cd yavuzlar-go-kullanicigirişlog
go run main.go
```

> Giriş sistemi bir öğrenme görevidir; kullanıcı bilgileri kodun içinde tanımlıdır, gerçek bir sistemde kullanılmak üzere yazılmamıştır.
